# 調整ガイド

## 設定の意味

| 設定 | 作用 |
|---|---|
| プレビュー目線高 | 確認用Humanoidアバターをこの目線高へ拡大縮小します。左目のボーンがない場合は頭ボーンを代用するので近似値です。保存するカメラには直接作用しません。 |
| プレビューアバターの向き | プレビュー中のアバターだけを回します。保存カメラの向きは変わりません。 |
| 元の想定目線高／合わせる目線高 | ボタンを押したときに全体倍率 = 合わせる値 ÷ 元の値を設定します。自動測定ではありません。 |
| 全体の倍率 | Pivotの位置とCameraのローカル位置を拡大縮小します。 |
| 上下の補正 | ルートのY軸方向に移動します。 |
| 左右の移動 | 最終的なカメラの右方向に平行移動します。プラスでカメラは右、被写体は画面の左に寄ります。 |
| 距離倍率 | Cameraのローカル位置の倍率です。Pivotにすべての位置移動があるカメラでは効果がありません。 |
| 左右に回す角度 | PivotをルートのY軸周りに回します。 |

補正は「全体倍率 → 水平回転 → 上下移動 → Camera距離倍率 → 画面基準の左右移動」の関係で適用されます。

## おすすめの確認順

まず倍率1、距離倍率1、移動と角度は0から始めます。全身の場面で全体倍率を決め、その後アップの場面で上下・左右を合わせてください。1か所だけに合わせると、別の場面で顔や足が切れる場合があります。

想定目線高を変更する操作と、確認用アバターの目線高を変更する操作は独立しています。使用先の目線高を両方に設定してから確認してください。

## よくある問題

### カメラを指定するとエラーになる

Animationウィンドウでカーブのパスを確認してください。`pivot`、`Camera`、`Main Camera`、独自のOffset階層などは、そのままでは対応しません。名前だけを変更すると別の構造を誤解釈する恐れがあります。元の変換方法を確認してください。

### キャラクターが見えない／後ろを向く

プレビューアバターの向きと時刻を変えて確認します。モーション自体が後ろ向きから始まる場合もあります。元カメラが想定するルート位置・回転が違う場合は、このプレビューだけで使用先と一致するとは限りません。

### 衣装が追従しない、ピンクになる

プレビューはアバターのアップロード処理を実行しません。必要なシェーダーを導入し、衣装を統合済みの確認用Prefabを使ってください。ランタイムスクリプトやModular Avatarの処理が必要な状態は再現できません。

### 動かない、またはアバターがポーズを取らない

確認用アバターはルートにAnimatorを持つHumanoidのPrefabを推奨します。確認用モーションと互換性があるAvatar設定か確認してください。再生モード中は編集プレビューと保存が無効になります。

### 保存結果が元と少し違う

補正カーブはフレーム単位で焼き込みます。元が曲線補間・高速なカットの場合、フレーム間で違いが出ます。書き出し後のファイルで実際の再生を確認してください。

### インポート後に消したい

`Assets/PokahiMmdCameraTools`を削除します。保存済みの調整カメラはそのまま使用できます。
