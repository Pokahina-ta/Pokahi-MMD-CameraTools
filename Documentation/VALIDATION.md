# 検証記録

2026-09-21 / Unity 2022.3.22f1 / Windows

SDKを含まない独立プロジェクトで検証しました。

- エディターコードのコンパイル成功。
- 自作の2秒・30fpsカメラで、上下・水平移動・倍率・距離・回転を同時適用。
- 61フレームのプレビュー計算と保存クリップの姿勢が位置誤差0.001m未満・回転誤差0.08度未満で一致。
- 画角の保持、元クリップの不変性、再生時間の保持を確認。
- NaNの倍率と非対応リグを拒否。
- 独立プレビューシーンのRenderTextureへの描画を確認。

この検証は任意の外部クリップやアバター、VRChat実機での完全な互換性を保証するものではありません。
