# Pokahi MMD Camera Tools

Unity上でMMDカメラの映像を確認し、上下・左右・距離・倍率・向きを調整して別の `.anim` に保存するエディターツールです。

**VRChat SDK・UdonSharp・VMD変換ツールのインストールは不要です。**

## できること

- 再生／一時停止／時刻指定による16:9プレビュー
- 任意のアバターPrefabとダンスモーションを使った構図確認
- 全体倍率、上下位置、画面基準の左右移動、距離倍率、水平回転の調整
- 想定目線高の比率から倍率を設定
- 原本を上書きせず、補正版のAnimationClipを作成

## 必要な環境

- Unity 2022.3（検証バージョンは [検証記録](Documentation/VALIDATION.md) を参照）
- 下記の階層に対応した、変換済みカメラAnimationClip
- アバターを使う場合は必要なシェーダー等を先に導入してください

VMDファイルの読み込み・リグ構造の変換・ワールドの作成機能は含みません。

## 導入

1. `Packages/Pokahi-MMD-CameraTools-0.1.0.unitypackage` をダウンロードします。
2. Unityで **Assets → Import Package → Custom Package** を選び、ファイルを指定します。
3. Importを押してコンパイルを待ちます。
4. **Tools → Pokahi MMD Camera Tools → カメラ調整・プレビュー** を開きます。

ソースから導入する場合は `Assets/PokahiMmdCameraTools` フォルダーを、プロジェクトのAssetsへコピーしてください。両方の方法を同時に使う必要はありません。

## 最初の調整

1. **カメラ**に変換済みのカメラ `.anim` を入れます。
2. **確認用アバター**にPrefab、**確認用モーション**にダンスの `.anim` を入れます。未指定でもカプセルで確認できます。
3. **プレビュー目線高**を使用先のワールドに合わせます。初期値1.5mは目線高であり、頭頂部までの身長ではありません。
4. **再生**または時刻スライダーで、冒頭・中盤・アップ・全身の場面を確認します。
5. 各補正を少しずつ調整し、**調整したカメラを別名で保存…** を押します。
6. 使用先のカメラAnimatorや曲登録ツールへ、保存したファイルを割り当てます。

[各設定とトラブル対処](Documentation/GUIDE.ja.md)

## 対応するカメラ構造

```text
Animationを再生するルート（名前は自由）
└── Pivot
    └── Camera  ← Cameraコンポーネント
```

カーブのパスは `Pivot` と `Pivot/Camera`。大文字・小文字を区別します。対応カーブは位置・回転・Cameraの `field of view` です。ルートの移動、スケール、その他のコンポーネント、オブジェクト参照カーブは対応していません。

プレビューのルート位置・回転はゼロ、スケールは1です。Cameraに回転カーブがない場合、ローカルY回転180度を初期姿勢として使います。再生側も同じ初期姿勢にしてください。異なるワールドのカメラを自動判別・自動変換する機能ではありません。

## 保存の仕組みと制限

- 元クリップを複製し、元のフレームレート（最大120fps）で補正結果をサンプリングします。
- Pivotの位置・回転とCameraの位置を再作成します。画角・Cameraの回転カーブは保持します。
- キー間を線形補間するため、元の曲線の補間や急なカットと完全には一致しない場合があります。
- サンプリングによりファイルが大きくなる場合があります。20万サンプルを超える保存は中止します。
- このツールはアバターの身長固定、表情、PhysBone、Modular Avatarなどの実行を再現しません。アバターのスクリプト・音声・カメラはプレビュー複製から除去します。
- VRChat上での見え方はBuild & Testで確認してください。任意のアバターを自動追尾して最適な構図を作るツールではありません。
